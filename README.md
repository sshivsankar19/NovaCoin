# Blockchain Crypto Miner

A blockchain-based cryptocurrency miner built from scratch using Python and Flask. The project implements a complete blockchain engine with Proof of Work mining, ECDSA wallets, digitally signed transactions, a transaction validation pipeline, mempool management, and REST APIs. The long-term goal is to extend the system with a web dashboard, MySQL persistence, MetaMask integration, sandbox mode, and mining pool support.

---

## Features

### Implemented

### Blockchain Core
- Custom Blockchain
- Genesis Block
- SHA-256 Block Hashing
- Proof of Work (PoW)
- Chain Validation
- Mining Rewards (Coinbase Transactions)

### Wallet System
- ECDSA (SECP256k1) Key Generation
- Wallet Address Generation
- SHA-256 + BLAKE2b Address Hashing
- Wallet Balance Calculation

### Transactions
- Transaction IDs (TXIDs)
- SHA-256 + BLAKE2b Transaction Hashing
- Digital Signatures
- Signature Verification
- Immutable Transactions
- Transaction Serialization
- Transaction Deserialization

### Validation Pipeline
- Signature Validation
- Public Key ↔ Wallet Address Verification
- Positive Amount Validation
- Self-Transfer Prevention
- Balance Validation
- Duplicate Transaction Detection
- Timestamp Validation

### Mempool
- Pending Transaction Management
- Transaction Queue
- Automatic Cleanup After Mining

### REST API

| Method | Endpoint | Description |
|---------|----------|-------------|
| GET | `/` | API status |
| GET | `/health` | Health check |
| GET | `/chain` | View blockchain |
| GET | `/wallet/new` | Create wallet |
| GET | `/wallet/<address>` | Wallet balance |
| GET | `/mempool` | View pending transactions |
| GET | `/transaction/<txid>` | Transaction explorer |
| POST | `/transaction/create` | Create and sign transaction (development endpoint) |
| POST | `/transaction` | Submit transaction |
| POST | `/mine` | Mine pending transactions |

## Cryptography

- SHA-256
- BLAKE2b
- ECDSA (SECP256k1)

Wallet addresses are generated by hashing the ECDSA public key using SHA-256 followed by BLAKE2b. Transaction IDs (TXIDs) use the same hashing pipeline for deterministic identification.

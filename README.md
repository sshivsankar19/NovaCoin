# Blockchain Crypto Miner

A blockchain-based cryptocurrency miner built from scratch using Python and Flask.

## Features

### ✅ Implemented
- Custom Blockchain
- Block Class
- Genesis Block
- SHA-256 Hashing
- Chain Validation
- Proof of Work Mining
- Mining Nonce
- Flask Backend API

### 🚧 In Development
- Transactions
- Wallet System
- Mining Rewards
- Pending Transaction Pool
- REST APIs
- Blockchain Explorer
- MySQL Integration
- Frontend Dashboard
- MetaMask Integration

### ⭐ Planned
- Dynamic Mining Difficulty
- Reward Halving
- Mining Pool Support
- External Pool Connection (Optional)
- Real-time Blockchain Statistics

## Tech Stack

- Python
- Flask
- Flask-CORS
- MySQL
- HTML
- CSS
- JavaScript
- MetaMask
